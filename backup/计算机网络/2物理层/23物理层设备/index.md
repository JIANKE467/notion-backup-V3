#  2.3物理层设备

### 中继器
长距离传输中，信号难免衰减变形
中继器可以将信号整形再生
- 只支持半双工通信
- 中继器一端对应一个网段
### 集线器
集线器真就是直接把多条线路合成一条，不做任何处理，因此集线器下的所有设备都处于一个冲突域（总线型网络）
冲突域：一个冲突域下的设备通信会互相干扰
- 现在都是交换机，没有用集线器的（太落后）
缺点：
不能隔离冲突域，通信冲突
所以设备共享带宽（相互挤兑）
更别说隔离广播（路由器）了
半双工通信，效率低
