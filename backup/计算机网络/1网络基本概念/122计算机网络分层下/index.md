# PDU、SDU、PCI的概念
- 协议数据单元（PDU）：本层的所有数据（控制数据，用户数据）
- 服务数据单元（SDU）：上一层的所有数据
- 协议控制信息（PCI）：本层的控制数据
- 三者关系：n-SDU+n-PCI=n-PDU=(n-1)-SDU 
# 协议三要素
- 语法：规定数据和控制信息的格式
- 语义：需要发出什么控制信息，怎么应答
- 同步（时序）：规定各种操作的条件，时序关系（如：发送方10秒没收到“传输成功”应答，则重传）
