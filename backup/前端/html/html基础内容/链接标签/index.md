#  链接标签

## 链接标签
<a>：双标签，行内元素
虽然<a>标签是行内元素，但也可以嵌套块级元素（特例）
### 属性
- `herf`属性：指定跳转的链接
- `target`属性：打开方式，默认值`_self`（当前页面打开），设为`_blank`（新窗口打开）
## 链接的用途
1. 外部跳转（herf属性填外部链接）
1. 内部跳转（herf属性填内部地址）
1. 使某个组件成为链接（将相应组件嵌套进去）
1. 锚点，可实现页内跳转（配合id属性使用，herf属性填`#+id`）
  例子：
  ```html
<div id="div1">
666
</div>

 <a href="#div1">链接</a>
  ```
这样，我们在点击链接时，页面就会自动滚动到对应位置，且浏览器顶部路径栏中会自动拼接此锚点。
