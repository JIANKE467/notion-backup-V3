#  **行内纵向对齐**

## 属性
vertical-align：控制行内元素的纵向对齐方式
## 值
- baseline：与文字基线对齐
- top ：与文字顶线对齐
- bottom ：与文字底线对齐
- middle ：与文字中线对齐
![](assets/3725a2dd-8276-80de-9caf-ce6a455b088e.png)
## PS
一般是给行内块设置vertical-align属性，让他和文字对齐
