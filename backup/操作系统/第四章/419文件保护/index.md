#  4.1.9文件保护

# 口令保护
在FCP中保存一段口令（字符串），访问时会与用户提供的口令对比，一致则通过验证
优点：口令保存和验证开销较小
缺点：口令明文存储，不安全
# 加密保护
使用密码加密文件，访问时要求提供密码
优点：安全性高
缺点：加密解密有一定开销
# 访问控制
在FCB中添加访问控制表，该表记录了各用户的权限，访问时验证权限
精简访问控制表：只记录用户组的权限
优点：比较灵活，精细
