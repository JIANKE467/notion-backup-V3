#  3.2.7内存映射文件

# 作用1：简化开发
内存映射文件把文件内容直接映射到进程虚拟地址空间中，开发者不需要再显式调用 read()、write() 进行数据拷贝
# 作用2：数据共享
多个进程可以映射同一个文件实现文件共享
传统做法：拷贝源文件到进程的内存中→修改→拷回去
问题：a进程改了，b不能实时看到
用进程映射文件就可以解决
# PS
使用内存映射文件后系统并不会立刻将对应文件拷到进程内存中，而是等运行到缺页时才会拷贝
文件完全由操作系统负责，系统可以进一步优化io效率
