#  盒子模型的概念

在盒子模型的概念中，为了方便浏览器布局，我们将每个组件都视为一个矩形盒子（无论是<p>标签还是<div>）
## 盒子的组成部分
一个盒子有四个部分
- 内容区（content）
- 内边距（padding）
- 边框（border）
- 外边距（margin）
**其中盒子大小默认是内容区大小**

这种标准很反直觉，不如IE当年的标准：“盒子大小就是所有区域总大小”
但IE标准寄了，所以现在很多项目会多做一步设置
```css
* {  
box-sizing: border-box;
}
/*将所有的盒子大小改为边框大小*/
```
**注意⚠️：**
**外边距不被算作盒子大小**
## 属性
box-sizing：控制盒子大小计算方式
## 值
- content-box： 只包含内容区
- border-box：连边距边框一起计算
