#  3.1.2内存分配-连续分配

# 单一连续分配
将内存分为系统区和用户区两个部分
- 用户区只能有一个用户程序，该进程独占用户区
优点：简单，不用考虑内存保护，无外部碎片
缺点：内存利用率低，一次只能运行一个进程，有内部碎片（分配的内存有大片未利用）
# 固定分区大小
将内存分为系统区和若干大小相等的用户区
或
将内存分为系统区和若干大小不等的用户区
- 每个分区可以装入一个进程
- 操作系统会维护一个分区说明表，用来记录各分区大小，起始地址，分配状态等
优点：实现简单，无外部碎片
缺点：无法满足超大进程（各分区都放不下），会产生内部碎片，利用率低
# 动态分区分配
系统不提前分区，在进程装入内存时才根据大小建立分区，且分区大小可变
- 系统`维护空闲分区`表或`空闲分区链`来记录分区情况
- 使用`动态分区分配算法`决定分区如何分配

# 名词解释
内部碎片：分配给进程的内存存在部分未被利用
外部碎片：内存产生了一些难以利用的空闲区域
PS：可以通过紧凑技术解决外部碎片（移动其他进程内存）
