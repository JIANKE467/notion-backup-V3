#  文本修饰

文本修饰就是设置下划线，中划线…等
## 属性
text-decoration：修饰文本
## 值
可以写多个值，如：颜色，修饰类型，大小，样式…
修饰类型：
- none：取消原有的划线
- underline：下划线
- line-through：中划线
- overline：上划线
线条样式：
- 实线solid
- 波浪线wavy
- 小点dotted
- 双实线double
- 虚线dashed
颜色：
预设值或rgb色
宽度：
相对宽度或绝对宽度
