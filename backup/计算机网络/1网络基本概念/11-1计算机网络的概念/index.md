#  1.1-1计算机网络的概念

# 计算机网络，局域网，因特网区别
计算机网络：网络的统称（局域网，互联网）
局域网：支持各种协议
因特网：只支持tcp/ip协议
# 网络设备
集线器：工作在一个网络下，但可能引起冲突
交换机：工作在一个网络下，处理一个网络的数据交换工作
路由器：将两个网络连接起来
# 拓展
ISP：是互联网服务提供商
家用路由器：路由器+交换机….
