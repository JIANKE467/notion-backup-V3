#  4.2.9ICMP网际控制报文协议

和ARP协议不同，ICMP协议不是直接封装在mac帧中，而是封装在IP数据报中，虽然但是，它仍属于网络层
典型应用：
路由追踪↓
IP数据报有一个TTL计数，每经过一次路由就会减1，当减到0时，路由器会将其丢弃，并返回ICMP报文

# ICMP报文常见类型
### 差错报告报文
- 终点不可达：目的IP不可达/目的端口不存在
- 超时：TTL=0（路程太远）/丢包
- 参数问题：参数不合法/首部校验出错
- 改变路由：网络层重定向（让源主机下次换条路线）
### 询问报文
- 回送请求：探测目标主机（ping）
- 回送回答：回应探测请求
- 时间戳请求：请求当前时间
- 时间戳回答：回应当前时间
### 不必反馈ICMP差错报文的情况
- ICMP差错报文本身出错
- IP数据报被分片，分片出错，只返回一次ICMP
- 目的地址是多播地址
- 源地址是特殊地址
