#  用户代理样式（浏览器默认样式）

用户代理样式就是浏览器的默认样式
我们之前学过三种样式引入方法：
1. 内联样式
1. 内部样式
1. 外部样式
现在还有一种样式
1. 用户代理样式

这种样式的优先级最低，它的作用是给没有写css的页面一个兜底样式（由浏览器提供）
不过有的浏览器有这东西，有的没有
**所以建议使用外部样式确保多端统一**
