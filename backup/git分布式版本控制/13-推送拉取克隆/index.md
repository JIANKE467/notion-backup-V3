#  13. 推送/拉取/克隆

# 推送
```shell
git push [-f] [--set-upstream][远程名称 [本地分支]：[远程分支]]
```
PS：
1. 本地/远程分支名一样,远端分支名可省略
1. -f：强制推送（强制覆盖）
1. `--set-upstream`：推送到远端的同时建立起和远端的分支关联关系
1. 如果已经和远端建立分支关系，则可以省略：远端和本地分支名、远端名（直接git push就行）
# 查看远程-本地分支对应
```shell
git branch -vv
```
# 克隆
```shell
git clone 仓库路径 [本地目录]
```
- 不填本地目录默认在当前路径
# 抓取和拉取
### 抓取fetch
```shell
git fetch [远程分支] [本地分支]
```
- 抓取命令只将远端更新下载到本地，不合并
- 不指定远端和本地分支名，则抓取所有分支
PS：
**Q：抓取不涉及合并，那它怎么处理相同的部分？**
**A：抓取会在本地创建一个“远端跟踪分支”，人手动合并本地分支和“远端跟踪分支”**
### 拉取pull（抓取+合并）
```shell
git pull [远程分支] [本地分支]
```
- 拉取相当于抓取（fetch）+合并（merge）
- 不指定远端和本地分支，拉取所有分支
