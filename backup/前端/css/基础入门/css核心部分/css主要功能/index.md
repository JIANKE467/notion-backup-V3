#  css主要功能

- 控制页面布局：设置元素的位置、大小、边距、边框等。
- 定义字体和颜色：设置文本的字体、大小、颜色、背景色等。
- 实现响应式设计：通过媒体查询适配不同设备（如手机、平板、桌面）。
- 动画与过渡效果：实现元素的动画、渐变、变换等交互效果。
- 样式继承和层叠：多个样式规则可以叠加应用，优先级由层叠规则决定。
