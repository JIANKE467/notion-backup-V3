#  明确一些概念

- 以太网=局域网
- 链路层传输的是mac帧，以太网交换机工作在这层
- ARP是路由表，在网络层
- 每台电脑都会存储ARP表，但不会存储mac表
- mac表由交换机维护
- 交换机通过识别mac来工作
- 电脑通过子网掩码+ip判断目标是否处于同一网络
- 目标不在同一网络，主机会将接收方mac填为网关mac
- 当接收方mac不在mac表中，交换机会“洪泛”查询（PS：就是王道说的在局域网内广播，他的说法不太标准）
