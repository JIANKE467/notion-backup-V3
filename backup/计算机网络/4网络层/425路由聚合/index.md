#  4.2.5路由聚合

# 路由聚合/构成超网
对于转发接口相同，部分网络前缀也相同的多条路由表项，可以合并成一条
- 路由聚合可以加快路由表查找
- 路由聚合可能引入一些无效地址（但不影响工作）
# 最长前缀匹配原则
当有多条路由都能匹配目的地址时，谁的子网掩码最长（/xx 数字最大），就优先选谁。
原因：掩码越长，匹配得越“精确”，优先级越高。
