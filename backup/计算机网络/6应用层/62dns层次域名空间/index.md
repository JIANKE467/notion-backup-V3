#  6.2DNS层次域名空间

### 域名书写规则
- 低级域名在左，高级域名在右
- 域名由标号组成，标号间用“.”分隔
- 标号：主要由英文（不区分大小写）、数字组成；允许用连字符“-”（其他标点不行）
- 单标号≤63字符，全域名总长（含点）≤255字符
