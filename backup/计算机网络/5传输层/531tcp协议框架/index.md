#  5.3.1TCP协议框架

- TCP首部较大，24b
- TCP支持报文拆分
- TCP有连接，可靠传输，支持拥塞控制
- TCP只支持一对一，不支持多对一
# TCP协议的三大阶段
### 建立连接（三次握手）
发送三个TCP报文段
### 数据传输
全双工通信
### 释放连接（四次挥手）
前两次挥手断开一方连接
后两次挥手断开另一方连接
