#  2.2传输介质

# 传输介质
  ## 导向型
    ### 双绞线
    有屏蔽层（STP）
    无屏蔽层（UTP）
    - 抗干扰：较好
    ### 同轴电缆
    一根导线+屏蔽层（闭路电视线）
    - 抗干扰：好
    ### 光纤
    纤芯+包层
    有单模光纤和多模光纤
    单模光纤（直线传输）：传输一种波长的光，长距离传输
    多模光纤（全反射）：传输多种波长的光，短距传输
    - 抗干扰：非常好
  ## 非导向型
    ### 无线电波
    - 穿透强
    - 距离远
    - 指向弱
    ### 微波/短波通信
    - 指向强
    - 易窃听
    - 带宽大
    ### 其他
    红外
    激光
# 以太网对有线传输介质的命名规则
  速度+Base+介质信息
  速度：
  纯数字，单位Mbps
  介质信息：
  - 同轴电缆：纯数字，数字×10就是传输距离
  - 光纤：F*，*可以是其他信息
  - 双绞线：T*，*可以是其他信息
# 物理层接口特性
  - 机械特性：形状，尺寸，引脚数，固定锁定装置
  - 电气特性：电压，长度，温度等
  - 功能特性：某个信号什么含义
  - 过程特性：发生某个事件怎么处理
