#  3.1.3两级页表

# 单级页表的问题
- 页表要连续存放，大内存进程光页表就会占很多内存
- 统计发现，现实只会频繁的使用页表的一少部分，页表的绝大多部分未被使用
# 两级页表的思路
把原来的大页表再分页
每个二级页表只管理一部分页面。
没有用到的二级页表根本不创建。
因此节省大量内存。
