#  类定义与对象创建

# 类创建
在src目录下，创建一个新的.java文件，就是创建了一个新的类，也可以先在src下创建包再在包里创建.java文件（在SRC下创建是因为编译器默认在SRC目录读取源码，在bin目录输出编译，lib放第三方库）
# 类定义
语法
```java
修饰符 class 类名{
成员变量;
成员方法;
...
}
```
- 类只有创建对象后才会实例化
# 对象创建
```java
类名 对象名 = new 类名(传入参数)；
```
- 创建对象时传入的参数是传给构造方法的
# 匿名类
- 匿名类是类定义+对象创建一步完成
- 匿名类由于没有名字无法二次调用
- 匿名类需要继承父类或实现接口才能使用（）
语法
```java
类名 对象名=  new 类名(传入参数){
成员变量;
成员方法;
...
};
```
