#  3.2.2请求分页内存管理

# 页表机制
普通页表中: 
| 页号 | 块号 |
| --- | --- |
| 1 | 5 |
| 2 | 3 |
请求分页中增加状态位: 
| 页号 | 块号 | 状态位 |
| --- | --- | --- |
| 1 | 5 | 0 |
| 2 | 3 | 1 |
其中状态位：
0→不在内存中（缺页）
1→在内存中
# 缺页中断机制
当发生缺页时，
有空闲内存→直接调入
无空闲内存→使用页面置换机制淘汰一个页面
PS：
缺页属于内中断的中的故障中断
```mermaid
flowchart TD
    A[中断] --> B[外中断]
    A --> C[内中断]

    B --> D[可屏蔽中断]
    B --> E[不可屏蔽中断]

    C --> F[故障 Fault]
    C --> G[陷阱 Trap]
    C --> H[终止 Abort]

    D --> I[I/O设备请求]
    E --> J[硬件故障报警]

    F --> K[缺页异常]
    F --> L[除零异常]

    G --> M[断点调试]
    G --> N[系统调用]

    H --> O[严重硬件错误]
```
