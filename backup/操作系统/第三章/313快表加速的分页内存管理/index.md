#  3.1.3快表加速的分页内存管理

# 什么是快表
快表是CPU中用于加速地址查找的高速缓存
传统内存分页管理需要先查存储在内存中的页表才能知道某个程序在内存中的位置
通过查快表可以省去CPU查询页表的过程
# 地址变换过程
比上节多了一个查快表的过程，如果快表命中，就不用查页表
