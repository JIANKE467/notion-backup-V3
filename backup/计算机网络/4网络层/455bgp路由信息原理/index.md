#  4.5.5BGP路由信息/原理

# BGP路由信息
### CIDR前缀
指向目的网络
### BGP属性
AS-PATH（自治系统路径）：描述到达目的网络需要经过哪些自治系统
NEXT-HOP（下一跳）
- 对eBGP：下一跳，是eBGP发送方路由器自己的IP（给隔壁发自己的IP）
- 对iBGP：默认不修改下一跳（隔壁AS的IP）
# BGP关键规则
- iBGP学到的路由不能再通过iBGP传播给其他邻居（边界路由器只会直接发给各BGP路由器，各路由器不会二次转发）
- 由于各路由器不会二次转发，所以需要在逻辑上确保所有路由器全联通
