#  泛型

Java在泛型以前，各类是没有定义类型的
也就是这样↓
```java
public class Test{
int a;
int b;
}
```
但这带来一个问题：很多类型冲突只有运行时才能发现
泛型推出以后，类型冲突可以在编译期被发现
## 泛型代表了什么
方法的类型代表了返回值的类型
而泛型的类型代表了该类允许传入的值（它是一个类型安全检查器）
## 类中要使用多种类型怎么办？
泛型支持定义多种类型
这就不得不提泛型的设计了，它没有设计成与方法传入参数一一对应的形式，而是由你定义一个或多个泛型变量及其对应的类型，在需要使用该类型的地方使用该泛型变量即可
至于你说要一个参数支持多种类型，你总得先找到合适的数据类型来定义方法吧，只要找的到，泛型就定义的了
## 那为什么要在类签名上加泛型
从功能上讲只要将泛型跟类型对应起来，再在相应位置使用泛型，就能达到目的了，为什么要在签名上加泛型？
泛型必须在类签名上声明，否则编译器会认为泛型类是真实类（在类签名上声明是告诉编译器哪些是泛型类）
这也回答了通配符只能在类调用的时候使用，在类定义时类签名中使用通配符是毫无意义的
