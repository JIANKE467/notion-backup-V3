#  静态内部类

前面我们介绍了成员内部类，它就像成员变量和成员方法一样，是属于对象的，同样的，静态内部类就像静态方法和静态变量一样，是属于类的，我们可以直接创建使用。
```java
public class Test {
    public static class Inner {
       
        }
}
```
### 注意⚠️
- 静态内部类不需要创建外部类的对象即可直接创建内部类的对象
- 静态内部类无法访问外部类的内容（因为整个静态内部类处于静态上下文中，静态上下文中并没有外部类）
