#  5.2.1UDP数据报

- UDP首部很小，只有8b
- UDP不支持报文拆分
- UDP无连接，不可靠，不支持拥塞控制
- UDP支持一对一（封装到单播IP数据报）和多对一（封装到多播IP数据报）
