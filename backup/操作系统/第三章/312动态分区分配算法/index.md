#  3.1.2动态分区分配算法

动态分区分配算法解决内存怎么分，分那个块的问题
# 首次适应算法
思想：从低地址查找，找到第一个能满足大小的分区
实现：系统维护一个空闲分区表或空闲分区链来确定怎么分（按地址顺序排列）
优点：不用重排链表
缺点：每次都从空闲分区表/链头遍历，开销大
# 最佳适应算法
思想：优先分配小空间
实现：系统维护一个空闲分区表或空闲分区链来确定怎么分（不过这个表/链是按从小到大的顺序排列）
缺点：有太多外部碎片
# 最坏适应算法
思想：优先分配大空间
实现：系统维护一个空闲分区表或空闲分区链来确定怎么分（不过这个表/链是按从大到小的顺序排列）
缺点：大进程容易得不到内存
# 临近适应算法
思想：改进首次适应算法，改从上次查找结束时的位置开始查找，找到首个适应的大小
实现：系统维护一个空闲分区表/链（按地址顺序排列），从上次查找的地方继续
优点：不用重排链表，解决了首次适应算法的问题
缺点：大内存进程容易没内存
