#  4.4.5BGP的四种报文

# Open打开报文
用来与相邻的另一个BGP对等方建立BGP会话，初始化通信
# Update更新报文
用来通知某路由信息，列出要新增/撤销的路由
# Keepalive保活报文
周期性通知BGP对等方“我还在线”
# Notification通知报文
用来发送检查到的错误，并立即关闭BGP会话
