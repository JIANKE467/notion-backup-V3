#  最大宽度和最小宽度

css除了绝对宽高width和height外，还有最大和最小宽高
这在响应式布局中很有用，可以防止元素变得过窄或过宽
## 属性
- `max-width`: 设置元素的最大宽度
- `min-width`: 设置元素的最小宽度
- `max-height`: 设置元素的最大高度。
- `min-height`: 设置元素的最小高度。
## 值
- 像素
- 百分比（占父元素的百分比）
