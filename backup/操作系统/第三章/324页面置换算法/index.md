#  3.2.4页面置换算法

# opt最佳置换算法
淘汰未来最长时间内不会再被访问的页面
优点：缺页率最低
缺点：实现不了（在实际中不可能知道未来要访问哪些页面）
# FIFO先进先出置换算法
淘汰最早进入内存的页面
优点：实现简单
缺点：可能频繁淘汰高频使用的页，造成严重缺页（Belady异常）
# LRU最近最久未使用置换算法
淘汰当前内存中最长时间未被使用的页
实现：在页表中新增一个访问字段，用来记录该页上次使用时间
优点：缺页率低
缺点：实现较复杂，开销大
# clock时钟置换算法
### 简单时钟置换算法
给页表中加一个访问位，用来记录最近是否被访问，用一个指针循环扫描各页的访问位并将其翻转，规则
- 扫描到0且缺页时则将该页换出
- 扫描到1则不换出
### 改进型时钟置换算法
基于简单时钟置换算法改进
其在页表中新增了一个修改位，记录页是否被修改，1→修改过；0→未修改，
依旧用一个指针循环扫描各页的访问位并将其翻转，规则（访问位，修改位）
- 扫描到（1，1）不会淘汰
- 扫描到（0，0）直接淘汰
- 扫描到（0，1）备选淘汰（没有（0，0）的情况）
- （1，0）不用说了，扫描完就翻转成（0，0）了
PS：
**改进关键：算法淘汰（0.，0）的块是直接丢弃，不是写回外存（因为没改），降低了IO频率**
