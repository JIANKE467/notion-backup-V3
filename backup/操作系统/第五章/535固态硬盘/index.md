#  5.3.5固态硬盘

# 固态硬盘结构
![](assets/37a5a2dd-8276-8028-8093-c66be151ad10.jpg)
- 固态硬盘按整页读写
- SSD的页对应HDD的块/扇区
- SSD的块对应HDD的磁道
- 闪存翻译层：将逻辑块号翻译成页
- 存储介质：闪存芯片
# 读写特性：


- 随机访问支持好
- 以页为单位读写
- 以块为单位擦除（NAND盘）
- 读快，写慢
# 与HDD相比
- HDD擦写几乎没有寿命
- SSD擦写有次数限制
- SSD安静，抗震
- HDD有噪音，不抗震
# 磨损均衡
- 动态磨损均衡
- 静态磨损均衡
