#  8. Git分支操作-常用指令

一个仓库内允许有多个分支，这些分支可以让多个并行的版本共存，分支也可以合并，用来协作
工作区只能挂载到一个分支上，看HEAD指向哪个分支
# 查看分支
```shell
git branch
```
# 创建本地分支
**要先切换到对应的分支再创建，否则就创建到别的分支下了**
```shell
git branch 分支名
```
# 切换分支（签出分支）
```shell
git checkout 分支名
```
**创建并切换分支**
```shell
git checkout -b 分支名
```
# 合并分支
**要先切换到目标分支再合并，否则就合并到当前分支下了**
```shell
git merge 分支名
#先切换到要合并到的分支再执行
#分支名填要合并的分支名
```
PS：一般都是其他分支合并到main/master分支
所以一般都是先切到main/master分支，在执行get merge命令
# 删除分支
```shell
git branch -d 分支名
```
**强制删除**
```shell
git branch -D 分支名
```
不能删除当前分支，要删除分支，得先切换到别的分支。
**没有合并过的分支，直接删除会报错，git认为你误操作了，这个时候就要使用强制删除**
