#  1.1-2计算机网络组成

# 硬件-软件-协议角度
  ## 硬件
  路由器
  交换机
  集线器
  调制解调器（猫）
  网络适配器（网卡）
  线缆
  ## 软件
  客户端
  ## 协议
  各种协议
# 工作方式角度
  ## 边缘部分
  各种终端
  ## 核心部分
  交换机等各种设施
# 逻辑功能角度
  ## 资源子网
  负责提供各种资源，如：文件，算力，等
  例：IDC服务商内网
  ## 通信子网
  负责联通整个网络
  例：ISP核心网
# 计算机网络功能
  数据通信：实现基本传输
  资源共享：硬件，软件，数据
  分布式处理：集群计算，边缘计算
  提高可靠性：主/备服务器
  负载均衡：多服务器负载均衡
  其他
