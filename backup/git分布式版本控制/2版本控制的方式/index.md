#  2.版本控制的方式

# 版本控制有两种方式
### 集中式版本控制
如svn和cvs
这两个已经过时，没必要学，没人用
集中式版本控制只允许维护一个版本（必须连接远程仓库）
### 分布式版本控制
如git 
分布式版本控制允许每个人都能维护一个版本（不必须连接远程仓库）
分布式版本控制允许两个人在没有中心服务器的情况下相互推送（一般不这么干）
