#  1.1-3-1电路交换，报文交换-分组交换

# 电路交换
电话网络
连接→通信
**优点：**传输速率高
**缺点：**建立连接时间长，占线无法传输，被干扰无法纠错

# 报文交换
电报网络
报文分两部分：控制信息，数据
**优点：**不用连接，不用独占线路，支持干扰纠错
**缺点：**
报文大小不固定难以管理存储转发
长报文需要整个发送，缓存开销大
长报文重传代价高
# 分组交换
计算机网络
由电报网络改进而来
将报文切分成若干组，每组包含首部和报文
**优点：**
无需建立连接
分组长度固定，方便缓存管理
支持校验
长报文无需整个发送
**缺点：**
控制信息占用了部分通信容量
每个节点要处理控制信息，有延迟
中途丢失分组导致后续处理复杂
# 虚电路交换（现代网络）
改进自分组交换
需要先建立连接（虚拟电路）
但不独占一条物理线路
