#  对象的调用

# 语法
```java
对象名.属性
```
例：
```java
Animal.color=blue;
```
# 注意
- 对象名存储的是一个引用，而非对象本体
- 数据类型分：基本数据类型，引用类型（开发者定义的所有“类”都是引用类型，以引用类型定义的变量只存储引用）（类似于指针）
- 以引用类型定义的变量允许空引用（不推荐）（Java没有空指针检查，因此可以通过编译，但可能会在运行时报错）↓
```java
Animal a=null;
```
- 普通变量使用前需要初始化，但对象中的变量不需要（JVM在创建对象时会自动初始化）
- 同一作用域下，变量名不允许重复，即使所属的类不同（对象本质就是存储引用的变量）
