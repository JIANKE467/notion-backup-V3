#  3.7.2 ppp协议（点对点协议）

链路层除了802.11，802.3还有ppp协议
ppp协议常用于宽带拨号，路由器间直联（ppp原生支持认证，而且不需要mac地址那些东西，协议简单）

# 如何透明传输
人话：当数据部分出现帧定界符如何处理？
### 方案a：字节填充（转义）
- 用于异步传输（没有时钟信号）
- 方案：将0x7E（帧定界符）转义为0x7D
### 方案b：零比特填充
- 用于同步传输（有时钟信号）
- 方案：防止数据部分出现01111110（帧定界符），给连续5个1后插一个0

# ppp协议特点
- ppp是链路层协议
- ppp只支持全双工
- ppp不是可靠连接（没有ack），但保证无差错（crc校验）
- ppp支持多种网络层协议（ipv4/6，AppleTalk）
- ppp帧是字节的整数倍（8的倍数）（规定）
