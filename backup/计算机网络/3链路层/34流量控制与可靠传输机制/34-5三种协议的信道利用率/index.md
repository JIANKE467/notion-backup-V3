#  3.4-5三种协议的信道利用率

信道利用率：
$$
U=\frac{T_D}{T_D+RTT+T_A}
$$
T_D：数据帧传输时延
RTT：2倍单向传播时延
T_A：确认帧传输时延
# S-W确认等待协议

# GBN（后退n帧协议），SR（选择重传协议）
计算公式
$$
U=\frac{NT_D}{T_D+RTT+T_A}
$$
N：一次性发送的帧数
PS：如果信道利用率大于1，则取1
# 术语补充：滑动窗口机制
在使用术语上：停止-等待协议不属于滑动窗口协议
滑动窗口协议指：后退n帧协议，选择重重传协议
|  | 停止等待协议 | 后退n帧协议 | 选择重传协议 |
| --- | --- | --- | --- |
| ARQ协议（自动重传） | ✓ | ✓ | ✓ |
| 连续ARQ（自动重传多个帧） | X | ✓ | ✓ |
| 滑动窗口协议 | X | ✓ | ✓ |
