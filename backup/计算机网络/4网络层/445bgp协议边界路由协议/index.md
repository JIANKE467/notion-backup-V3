#  4.4.5BGP协议（边界路由协议）

# BGP特点
- BGP只求找到AS较好的路由（不求最好）
- BGP协议用于各AS间通信
- BGP需要考虑政治/经济问题（如：C国不希望数据转发经过A国）
- BGP采用路径向量路由算法（路由器之间通报bgp路由信息时，不仅告知目的地，还告知完整路径）
- BGP是应用层协议
# 哪些路由器要运行BGP协议
各AS边界路由器
部分核心路由器
# BGP会话
运行BGP的路由器间会建立BGP会话
其中
- 两AS的边界路由器间使用直连线路，建立eBGP会话
- AS内部的各BGP路由器间要建立全连通的iBGP会话（不一定直连）
