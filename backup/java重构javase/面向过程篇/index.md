[ 第一章：Java 程序基础](第一章java-程序基础/index.md)
  程序代码基本结构
     以下是最基本的 Java代码结构
    ```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
    ```
    其中，这是每个 Java 程序必须有的“主方法”（c语言叫主函数）（程序入口）
    **PS：与c不同的是，JAVA一个类只能有一个程序入口，但允许多个类有多个程序入口（此时需要指定要运行的类）**
    ```java
public static void main(String[] args)
    ```
    - 每句代码间用`；`隔开
    - 主方法是固定格式`public static void main(String[] args)`
    - Java 不像 Python，它的代码不靠空格和换行分隔
    - Java 只要有主方法就能运行，不一定需要创建类和包

    常用方法
    调试中常使用方法`System.out.println("")`来将结果打印到控制台

    ```java
void main ()
    ```

  变量和常量
    # 变量
     Java 定义变量需要手动指定变量的数据类型
    ```java
数据类型 变量名； 
    ```
    变量名有以下要求：
    - 标识符可由大小写字母、数字、下划线(_)和美元符号($)组成，不能以数字开头
    - 变量不能重复定义，大小写敏感
    - 不能有空格、@、#、+、-、/ 等符号
    - 应见名知意
    - 不能与关键字重名
    PS：Java语法允许使用中文变量名，但不推荐（兼容性极差）
    ## 变量赋值/定义
    可以初始化赋值
    ```java
int a=1；
    ```
    可以先定义后赋值
    ```java
int a；
a=1；
    ```
    也可以一次定义多个变量（逗号隔开）
    ```java
int a，b；
    ```
    # 常量
    Java 的常量是基于变量定义的
    在变量前加上 final 修饰符，使变量不可修改
    ```java
final int a；
    ```
    常量赋值后不可修改（未初始化的变量可以赋值一次）
[第二章：基本数据类型](第二章基本数据类型/index.md)
  整数类型
    在Java中，整数类型包括以下几个：
    - byte 字节型 （8个bit，也就是1个字节）范围：-128~+127
    - short 短整形（16个bit，也就是2个字节）范围：-32768~+32767
    - int 整形（32个bit，也就是4个字节）最常用的类型：-2147483648 ~ +2147483647
    - long 长整形（64个bit，也就是8个字节）范围：-9223372036854775808 ~ +9223372036854775807
  类型转换
     Java 中有两种类型转换：隐式类型转换（自动类型转换），显式类型转换（手动类型转换）
    # 隐式类型转换
     这是自动发生的，当不同数据类型的变量进行运算时，范围小的数据类型会转换成范围大的数据类型
    当需要将范围大的数据类型转换成范围小的类型时，隐式转换不会发生，这需要显式类型转换来完成（原则上是这样，但存在特殊情况，如：long（64bit）允许隐式转换成float（32位），这可能损失精度）

    byte→short(char)→int→long→float→double
    # 显式类型转换
    语法
    ```java
(目标类型) 变量名
//注意，这个不完整，仅说明基本写法，实际使用需要将转换完的结果赋值给某个变量
    ```
    eg：
    ```java
int a；
float b=1.35；
a=(int)b;
    ```
  浮点类型
    Java 中有这几种浮点类型
    - float 单精度浮点型 （32bit，4字节）
    - double 双精度浮点型（64bit，8字节）
    # 注意：
    - 所有小数默认是 double 类型（即使它是一个常量）**（这是Java 众多该死特性中的一个）**（具体含义见下面代码）
    ```java
float a=1.56  //❌报错，因为数字1.56默认是double型，float精度＜double精度

float a=1.56F //✅正确，给常量后面添加大写/小写F表示这是一个float型常量值
    ```
    - 相反，大范围的double类型可以直接接收小范围的float类型（发生隐式类型转换）
    - long类型（64bit）可以自动类型转换为内存更小的float类型（32bit），原因：虽然可能损失精度，但由于float类型带指数所以实际能表示的范围其实是更大的，编译器容许了😇
    - 使用浮点类型可能出现下面的情况（**计算机使用2进制表示浮点，部分浮点无法用二进制精确表示**）（解决办法：使用Decimal）
    ```java
System.out.println(0.1+0.2==0.3)
//结果输出fales
    ```
    # 每日喷Java
    Java的自动类型转换（隐式类型转换）的原则原则和c语言一样，并不能用“不丢精度就可以自动转换”或“小范围可以自动转换为大范围”来概括
    而是只能根据Java和c规定的转换路径进行转换
    这导致了类型转换逻辑非常混乱
    go语言完全解决了这个问题（删除了自动类型转换，所有转换必须显式进行）

[第四章：流程控制](第四章流程控制/index.md)
  代码块与作用域
    除了类，方法等需要用花括号包裹内容外，也可以随意创建代码块，如
    ```java
public static void main(String[] args) {
    int a = 10;   //此时变量在最外层定义
     {
     System.out.println(a);   //处于其作用域内部的代码块可以使用
     }
    System.out.println(a);   //这里肯定也可以使用
}
    ```
    - 创建代码块不会改变执行顺序(仍然按先后顺序执行）
    - 代码块会改变其中变量的作用域（在代码块中定义的变量作用域只能在代码块中）
  选择结构 （分支语句）
    # 语法
    条件成立，执行单行内容：
    ```java
if (条件判断) 判断成功执行的代码;
    ```
    条件成立，执行多行内容：
    ```java
if (条件判断) {
判断成功执行的代码;
}
    ```
    条件成立执行某语句，条件不成立执行另外一些语句：if-else语句
    ```java
if (条件判断) {
语句1;
}else{
语句2;
}
    ```
    - 如果没有else，条件不成立将直接跳过分支语句
    if-else语句支持嵌套，以实现多层选择
    ```java
if (条件1) {
语句1;
}else if(条件2){
语句2;
}else if(条件3){
语句3;
}else{
语句4;
}
    ```
    同样的，if语句也支持嵌套
    ```java
if (条件) {
  if (条件) {
  语句;
  }
}
    ```
  多分支语句
    # 语法
    ```java
    switch (输入选项) {  
        case '选项A':    
            语句A;
            break;   
        case '选项B':
            语句B;
            break;
        case '选项C':
            语句C;
            break;
    }
}
    ```
    - switch语句只能处理switch语句中定义好的准确选项，无法按数值范围处理（**`switch`****可以精准匹配某个值，但是它不能进行范围判断**）
    - **每个独立选项必须用break结束，否则会被视为与下个选项合并执行**
    - 可以用default来表示未定义的选项如何处理
    # java14（switch语法修改）
    分支结果直接作为返回值：
    ```java
int score = 9;
//直接让grade接受switch的结果
char grade = switch (score) {
    case 10, 9 -> 'A';   //case后面直接使用->来指定返回结果
    case 8 -> 'B';
    case 6, 7 -> 'C';  //当存在多个匹配条件时，使用逗号分隔
    default -> 'D';
};  //别忘了这种写法相当于赋值，最后需要加分号
System.out.println("学生等级为: " + grade);
    ```
    分支存在其他操作：
    ```java
char grade = switch (score) {
    case 9 -> 'A';
    case 8 -> 'B';
    case 6, 7 -> {
        System.out.println("我是额外操作");   //存在前置操作，无法直接指定结果
        yield 'C';   //在最后使用yield关键字来指定结果
    }
    default -> 'D';
};
    ```
    - 新版switch语句支持分支结果直接作为返回值给到前面的变量（使用->来指定返回结果）
    - 新版switch语句不需要break来结束，他是自动结束的
    - 分之存在其他操作，需要手动使用yield来指定返回值
  循环
    # for循环（前置条件循环）
    ### 语法
    ```java
for (初始化语句;循环条件;调整条件) {
循环体;
}
    ```
    - 初始化语句,循环条件,调整条件可以省略
    - 可以通过Continue来跳过本次循环，用break来结束循环（当有多层嵌套时，他们只作用于当前代码块中的循环）
    - for循环是前置条件循环
    ```java
for (int i = 0; i < 3; i++) {
        if(i == 1) continue;   
        if(i == 5) break; 
 }
    ```
    如果你非要在内层结束外层循环
    可以在循环前面打上标记↓（不推荐）
    ```java
outer: for (int i = 1; i < 4; ++i) {   //在循环语句前，添加 标签: 来进行标记
    inner: for (int j = 1; j < 4; ++j) {
        if(i == j) break outer;    //break后紧跟要结束的循环标记，当i == j时终止外层循环
        System.out.println(i+", "+j);
    }
}
    ```
    # while循环（前置条件循环）
    ### 语法
    ```java
while(循环条件) {
循环体;
}
    ```
    - whilie是前置条件循环
    - 同样可以使用continue和break
    # do-while循环（后置条件循环）
    ### 语法
    ```java
do{
循环体;
}while(循环条件);
    ```
    - 同样可以使用continue和break
    - do-while是后置条件循环
