#  文本域

<textarea>标签：声明文本域（双标签）
### 属性
rows属性：控制文本域的默认行数
col属性：控制文本域默认的列数
maxlength属性：限制最大输入长度
placeholder属性：提示信息
disabled属性：关闭文本域（布尔属性）
readonly属性：将文本域设成只读（布尔属性）
PS：文本域的默认内容直接写到两个标签中间即可
