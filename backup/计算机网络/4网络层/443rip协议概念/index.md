#  4.4.3RIP协议概念

# RIP协议在协议栈的位置
  RIP属于应用层协议，它使用UDP传输数据
  ### RIP的两种报文
  - Request报文：请求邻居发生路由表
  - Response报文：响应请求，携带部分或完整路由表
# RIP规定
  ### RIP如何定义路径长度
  1. RIP使用跳数衡量路径长度
  1. 跳数最少的路径最好
  1. RIP规定最大路径长度不能>15（只适用于小型自治系统）
  ### RIP如何定义路由表格式
  1. 每个路由器都要维护自己的路由表，路由表有三个字段↓
  ```plain text
<目的网络N，距离d，下一跳路由器地址X>
  ```
  1. 每个路由器都会维护距离向量（从路由器到每个目的网络的距离记录）
# RIP如何在路由器间交换信息
- 和谁：只和邻居交换信息
- 什么信息：自己的全部路由表
- 什么时候：通常按固定时间交换，也可以引入触发更新机制（立即交换）
