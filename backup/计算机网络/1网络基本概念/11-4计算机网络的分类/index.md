#  1.1-4计算机网络的分类

# 按分布范围
  ### 广域网（WAN）：
  跨省/跨国/跨洲
  技术：后面介绍
  ### 城域网（MAN）：
  跨城市
  技术：常采用以太网技术
  ### 局域网（LAN）：
  学校/企业/家庭
  技术：以太网技术
  ### 个域网（PAN）：
  家庭/智能家居网络
  技术：蓝牙/zigbee
# 按传输技术分
  ### 广播式网络
  该广播覆盖范围内所有设备都能收到
  如：WiFi
  ### 点对点网络
  只会点对点发送
# 按拓扑结构分
  ### 总线型
  数据“广播式”传输
  有争总线问题
  ### 环形网络
  依旧“广播式”传输
  通过令牌解决争总线问题，令牌顺环型传输，持有令牌才能使用总线
  ### 星型结构
  独立连接，点对点
  不存在争总线
  ### 网状结构
  数据通过多个节点转发
  点对点传输
# 按使用者分
  共用网
  专用网
# 按传输介质
  有线网络
  无线网络
