#  文本空白处理

本节介绍了对于代码中的空格和换行该如何处理
默认忽略空格和换行
## 属性
white-space：声明代码中的空格和换行该如何处理
## 值
- pre ：保留源码空格和换行 ，其他情况一律不换行（除了<br>标签）
- pre-wrap ： 同上，但超出宽度换行
- pre-line ：不保留源码空格序列，只保留源码换行
- nowrap ：完全禁止换行
