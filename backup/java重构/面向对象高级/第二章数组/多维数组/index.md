#  多维数组

这里的多维数组与c一致
# 定义
依然有两种写法
### 写法1（推荐）
```java
数据类型 [][] 数组名;
```
```java
int[][] arr;
```
### 写法2（兼容c）
```java
数据类型 数组名[][];
```
```java
	int arr[][];
```
# 访问
访问与一唯数组一致
# 其他要点
与一维数组一致
