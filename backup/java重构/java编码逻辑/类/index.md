#  类

>  J**ava中，类用来将一个业务拆分成不同模块，每个模块就是一个类（为了提高可维护性）**
下面是常见的分类法（不局限于这种分类法）
# 类的分类
  ### 测试类/main类
  有main方法
  不负责业务逻辑
  只负责运行
  ### Javabean类/数据类
  通常只存数据，没有复杂逻辑
  ### 工具类/Utils
  提供通用方法
  可重复使用
  ### service类/业务类
  处理业务逻辑
  ### DAO类/数据库访问类
  专门操作数据库
  ### Controller类/控制类
  接收请求
  调用service
