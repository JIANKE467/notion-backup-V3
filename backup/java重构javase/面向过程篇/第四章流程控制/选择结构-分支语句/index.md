#  选择结构 （分支语句）

# 语法
条件成立，执行单行内容：
```java
if (条件判断) 判断成功执行的代码;
```
条件成立，执行多行内容：
```java
if (条件判断) {
判断成功执行的代码;
}
```
条件成立执行某语句，条件不成立执行另外一些语句：if-else语句
```java
if (条件判断) {
语句1;
}else{
语句2;
}
```
- 如果没有else，条件不成立将直接跳过分支语句
if-else语句支持嵌套，以实现多层选择
```java
if (条件1) {
语句1;
}else if(条件2){
语句2;
}else if(条件3){
语句3;
}else{
语句4;
}
```
同样的，if语句也支持嵌套
```java
if (条件) {
  if (条件) {
  语句;
  }
}
```
