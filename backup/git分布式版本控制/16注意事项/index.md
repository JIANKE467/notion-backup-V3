#  16.注意事项

### 切换分之前先提交本地的修改
为git并非一个分支一个文件夹，各分支的内容是混在一起的
所以切换分支必须要覆写工作区，没有办法直接切换文件夹挂载（因为没有分文件夹）
所以不提交直接切换工资，一定会导致修改丢失
