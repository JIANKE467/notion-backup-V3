#  再谈集合类

我们会发现随着线程的引入，很多原先的集合类都出现了线程不安全的问题（由于这些集合类没有加锁，可能出现同时两个线程更改同一个数据的问题造成冲突）
其实不仅仅是集合类，还有很多类并不具备线程安全
