#  JavaAPI

进入泛型，匿名内部类后是不是感觉很乱，那是因为Java进入了新的阶段，也就是JavaAPI，这时不能在用原来的方式来分析代码
那怎么办呢？

学习方法：如学习一个类，只需要知道它实现了什么接口，功能是什么，有哪些方法，有什么注意事项？无需了解它是怎么实现的（顶多知道它是使用正常方法实现的接口还是匿名内部类实现的接口【知道对象引用给谁】），知道方法传入什么传出什么
更深一点：知道类的继承关系
所需技能：泛型，匿名内部类，Lambda表达式
需要知道的点：Java一切皆对象（想用某个类？先创建对象）
