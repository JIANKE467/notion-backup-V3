#  z轴顺序

当多个元素发生重叠时，z轴顺序决定，谁在上面，谁被挡住
默认情况下，DOM顺序（标签顺序）靠后的会覆盖靠前的
## 属性
z-index：设置z轴优先级（数大的在上面）
## 值
- 只能是整数
## 注意⚠️
z轴顺序不会对普通文档流元素生效，只对设置了定位方式的元素生效
