#  6. 创建本地仓库

要想使用git进行版本控制，首先要创建本地仓库
# 步骤：
1. 在任意位置创建一个空目录，作为本地仓库
1. 在该目录中，右键打开git bash窗口
1. 执行命令
```shell
git init
#初始化当前目录为git仓库
```
1. 如果创建成功，会在该目录中看到一个 `.git`文件夹
