#  3.6.3 VLAN虚拟局域网基本原理

## 虚拟局域网（VLAN）
- 一个大型局域网可划分成多个VLAN
- 每个VLAN是独立的广播域
- 每个VLAN对应一个VID
## 划分VLAN好处
- 防止设备过多导致广播包占用过多网络资源
- 安全
# VLAN划分方式
  ### 1. 基于接口
  设备连接固定的接口，交换机将广播帧广播到对应接口上就行了
  缺点：设备不能改变接口
  ### 2. 基于mac地址
  设备随便连接接口，交换机将广播帧转发到固定的mac地址的设备上
  缺点：设备不能开随机mac
  ### 3. 基于ip地址
  设备随便连接接口，交换机将广播帧转发到固定的IP地址的设备上
  缺点：需要网络层支持
# 802.1Q帧
  - 主机之间，主机与交换机之间使用标准以太网帧
  - 交换机之间，使用802.1Q帧
  区别：802.1Q帧在以太网帧的基础上增加了4位VID信息（VLAN编号）
