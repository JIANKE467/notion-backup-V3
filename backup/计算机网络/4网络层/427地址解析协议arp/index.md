#  4.2.7地址解析协议ARP

ARP协议和IP协议上同级别的，它们都会交给链路层，通过修改以太网mac帧的类型字段来做区分（0x0806代表数据部分是ARP分组）（0下0800代表数据部分是IP数据报）
# 回顾
- mac地址出厂自带，全球唯一
- 一台主机至少有一个mac
- 一个路由器一个端口有一个mac
# ARP协议
## **作用：**
ARP协议用来查询IP和mac的对应关系
## **ARP表：**（ARP缓存）
- 记录mac和IP的映射关系
- 每台主机/路由器都有自己的ARP表
- 需要定期更新ARP表
## ARP请求
内容：源IP，源mac，目的IP
发送方式：将ARP请求封装进mac帧，帧目的地址设为全1（广播帧）
## ARP响应
内容：源IP，源mac
发送方式：将ARP请求封装进mac帧，单播发送
