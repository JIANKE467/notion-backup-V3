#  4.4.2分层路由协议

# 存在的问题
- RIP路由协议缺点：基于距离-向量路由算法，连接全世界，需要的距离向量过多（存不下）
- OSPF协议缺点：基于链路状态路由算法，连接全世界，需要的网络拓扑巨大（不现实）
# 解决方案
- 将全世界的网络分成多个独立的自治系统AS
- AS可以决定在其网络中使用什么路由协议
- 每个AS通过至少一个自治系统边界路由器与其他自治系统连接
- 边界路由器间使用统一的协议：BGP协议
- 自治系统内的路由选择称为域内路由选择
- 自治系统间的路由选择称为域间路由选择 
### PS：
- 自治系统间是平级关系，不存在包含
- 每个自治系统都有唯一AS编号
- 每个自治系统内有一个或多个CIDR地址块
### 互联网把路由协议分两大类：
1. 内部网关协议IGP：RIP，OSPF
1. 外部网关协议EGP：BGP
