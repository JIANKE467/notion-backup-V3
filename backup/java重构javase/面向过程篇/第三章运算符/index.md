#  第三章：运算符

# 基本运算符
| 运算符 | 名称 |
| --- | --- |
| = | 赋值运算符 |
| + | 加法运算符 |
| - | 减法运算符 |
| * | 乘法运算符 |
| / | 除法运算符 |
| % | 取模运算符（取余） |
- 加法运算符还有拼接字符串的作用（也可以拼接其他数据类型内容）
```java
String str = "伞兵" + true + 1.5 + 'A';
```
- 两个int类型相除默认会丢弃小数部分，浮点型则不会
# 括号运算符
- 括号运算符采用小括号
- 括号运算符可以提升优先级
- 在一个数或者变量的前面加上括号运算符可用于强制类型转换
# 自增自减运算符
| 运算符 | 作用 | 示例 |
| --- | --- | --- |
| ++ | 按1自增 |  |
| - - | 按1自减 |  |
| += | 按指定大小自增 | a+=4 |
| -= | 按指定大小自减 | a-=4 |
| *= | 按指定大小自乘 |  |
| /= | 按指定大小自除 |  |
| %= | 按指定大小自取余 |  |
- ++a与a++，不一样，前者是先自增后赋值，后者是先赋值后自增
# 位运算符（二进制）
| 运算符 | 名称 |  |
| --- | --- | --- |
| & | 按位与 |  |
| ｜ | 按位或 |  |
| ^ | 按位异或 |  |
| ～ | 按位取反 |  |
| >> | 向右移动指定位 | a>>2 |
| << | 向左移动指定位 |  |
| >>> | 无符号右移 |  |
| 没有无符号左移 |  |  |
- 移动后缺少的位用0补齐
- 无符号右移是连同负号的二进制一起移动
# 关系运算符
| 运算符 | 含义 |
| --- | --- |
| > | 大于 |
| < | 小于 |
| > = | 大于等于 |
| < = | 小于等于 |
| == | 等于 |
| ！= | 不等于 |
# 逻辑运算符
| 运算符 | 含义 |
| --- | --- |
| && | 与运算 |
| ｜｜ | 或运算 |
| ！ | 非运算 |
此外，还有一个三元运算符
```java
判断语句 ? 结果1 : 结果2
//判断语句成立输出结果一，不成立输出结果二
```
