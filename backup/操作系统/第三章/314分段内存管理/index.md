#  3.1.4分段内存管理

# 什么是分段内存管理
与分页内存管理不同，分段不是死板的将内存分为几个固定的区域，而是按逻辑功能分为几个“段”
如：
代码段（程序指令）
数据段（全局变量）
堆（动态分配内存）
栈（函数调用和局部变量）
# 分段地址结构
分段内存管理的逻辑地址与一般的不同，它是这种格式
```plain text
逻辑地址 = <段号, 段内偏移量>
```
# 地址转换过程
操作系统维护一张段表
表包含：段基址（段起始地址），段长度
地址转换↓
```plain text
逻辑地址→检查是否越界→计算物理地址
物理地址=段基址+段内偏移量
```
# PS
- 分页对用户是透明的，分段对用户不透明
- 分段可以更好的保护信息和进程安全
- 分段更容易实现共享
