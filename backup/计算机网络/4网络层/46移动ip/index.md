#  4.6移动IP

手机等设备移动到异地可能造成子网改变，如何处理这种改变
4/5G不适用
# 通信过程
  ## 移动站在本地网络
    和正常有线通信一样
  ## 移动站在外地网络
    - 移动站要向外地代理登记，获得临时的转交地址
    - 外地代理向本地代理登记该主机的转交地址
    移动站接收IP分组
    ```plain text
发送方
↓
本地代理
↓
外地代理
↓
移动站
    ```
    本地代理收到IP数据报后，会再套一层IP封装，目的地址写转交地址，发给外地代理
    移动站发送IP分组
    ```plain text
移动站
↓
外地代理
↓
直接转发到目的网络
    ```
# 注意⚠️
这节指的是传统移动IP的原理：
对于漫游设备，接收的数据要先回归属地，再由归属地转发，发送的数据可以直接发送
后来引入了改进：
如果收发同城，即使漫游数据也不用回归属地
移动IP难以和nat兼容
