#  5.2.2 假脱机技术

# 什么是脱机技术
脱机技术：脱离主机进行输入输出
背景：早期电脑io速度慢（纸带机io），为了加速io，会先用纸带机读取到磁带中，主机再从磁带中读取
核心思想：利用高速缓冲来提高慢速设备性能
