#  3.8以太网交换机

交换机=多端口网桥
以太网=局域网
# 自学习功能
- 交换维护一个交换表（记录mac+端口）
- 交换表初始为空
- 每收到一个帧就将发送方mac地址记录到交换表
- 如果交换机不知道接收方端口，就把帧广播到除入口外的其他端口
- 如果知道接收方端口，就转发到对应端口
- 交换表中每个项都有“有效时间”，过期作废（防止端口改变导致错误）
# 两种交换方式
### 直通交换
检查帧的目的地址后，直接转发给目标
优点：时延低
缺点：不适用需要速率匹配，协议转换，差错检查的线路
### 存储转发交换
交换机先将帧接收到内部的缓存中，进行差错检查后，再发给对应端口
优点：适用于需要速率匹配，协议转换，差错检查的线路
缺点：时延高
