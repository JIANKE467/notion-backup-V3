#  字符串类增强（Java11）

在Java11后String类增加了一些功能
### `strip`方法
String类型新增了strip方法，他会自动去除字符串的**前后的空格**
### stripLeading方法
String类型新增了stripLeading方法，他会自动去除字符串的**前的空格**
### stripTrailing方法
新增stripTrailing方法，它能自动去除字符串**后的空格**
### isBlank方法
新增isBlank方法，它能识别字符串是否为纯空格组成
### repeat方法
新增repeat方法，它可以让字符串重复排列（传入参数为重复次数）
