#  轮询访问-令牌传递协议

特点：环形拓扑，各节点轮询访问，不存在冲突
# 协议要点
### 令牌帧
- 需指明当前获得令牌的节点编号
- 只有获得令牌才能发送数据帧
- 如果获得令牌的节点没有数据发送，就将令牌传给下一个节点
### 数据帧
- 需指明源地址，目的地址，是否被接收，获得令牌的节点编号
- 数据帧从源节点发出，传递一圈后回到源节点
- 数据传递到目的节点后会被复制一份，并标记为已接收
- 数据帧回到源节点后如有异常，尝试重发
### 其他
- 无论是令牌还是数据帧，只能单向传输
- 获得令牌的节点，只能发一帧，发完释放令牌
- 需要专用设备MAU集中控制
- 令牌环网适合负载高的网络（不冲突）
