#  明确一些概念

- 网络ID：就是ip和掩码按位与的结果（一般不常用这个）（一般是这个网段的第一个ip）
- 子网掩码：表示网络号长度（将十进制转换成2进制，1的个数就是网络号位数）（只允许连续的1，有间隔的0则掩码不合法）
