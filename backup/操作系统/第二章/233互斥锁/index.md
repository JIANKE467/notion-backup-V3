#  2.3.3互斥锁

互斥锁：
基于acquire（）和release（）函数的硬件机制实现互斥访问的锁叫做**互斥锁**
互斥锁缺点：
忙等待，CPU需要循环调用acquire（）达到锁住的目的，浪费部分时间片
自旋锁：
进程拿不到访问权限就不退出就绪队列，一直循环检查锁是否释放（如TSL指令，swap指令）
