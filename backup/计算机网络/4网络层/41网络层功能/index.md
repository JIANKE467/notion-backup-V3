#  4.1网络层功能

# 异构网络互联
每个网络物理层，链路层实现不同，网络层负责屏蔽这些差异，让各种网络实现互联
设备：路由器
注：在TCP/IP文献中，路由器也叫网关gateway
# 路由与转发
### 路由
路由器通过路由协议，规划IP数据报的最佳转发路径
PS：各路由器运行路由协议，生成各自的路由表
### 转发
路由器根据自己的转发表，将IP数据报转发到对应的接口
PS：转发表是路由表的精简
# 拥塞控制
### 开环控制（静态）
在部署网络时预设的缓解拥塞的方法，部署完成不再修改
### 闭环控制（动态）
动态监视网络状态，发现拥塞后将拥塞信息传递给对应路由器（ICMP协议）
路由器会自动调整路由表和策略缓解拥塞
# 注意⚠️
网络层的IP协议不提供可靠传输
可靠传输靠链路层的TCP协议或其他协议
