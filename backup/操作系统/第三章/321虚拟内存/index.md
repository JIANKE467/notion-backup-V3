#  3.2.1虚拟内存

# 传统内存管理算法缺点
- 碎片问题（内部碎片和外部碎片）
- 内存利用率不足，无法支持比物理内存更大的程序运行
- 内存中存在大量使用率低的数据
# 局部性原理
时间局部性
如果一个数据被访问过，那么在不久的将来很可能再次被访问。
空间局部性
如果访问了某个存储单元，那么其附近的存储单元很可能很快被访问
# 虚拟内存特性
多次性（离散性）
一个程序不必一次全部装入内存，可以分批装入
对换性（交换性）
当内存空间不足时，将暂时不用的页面换出到磁盘，需要时再换入内存
虚拟性
逻辑上扩充了内存容量，对用户透明
# 虚拟内存的实现方式
主要有三种：
请求分页系统（基于分页内存管理）
请求分段系统（基于分段内存管理）
请求段页式系统（基于段页式内存管理）
PS
相对于传统的离散内存管理，虚拟内存技术多了两个功能：
- 请求调页/段（缺页/段时）
- 页面/段置换（内存不足时）
虚拟内存基于分页内存管理，实现了内存扩展
