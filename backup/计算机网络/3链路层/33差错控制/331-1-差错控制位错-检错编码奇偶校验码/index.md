#  3.3.1_1 差错控制（位错）-检错编码（奇偶校验码）

对于链路层来说有这几种出错可能：帧内错误（差错控制），帧间错误（可靠传输）
**本节讨论的是帧内错误的处理（差错控制）**
# 数据链路层的差错控制（位错）
  为了修复帧内的位错，有两种方式
  - 使用检错编码检测，发现错误后丢帧重传
  - 使用纠错编码检测，发现错误后修正
# 数据链路层的可靠传输（帧错）（后面说）
  要注意区分差错控制（位错）和可靠传输（帧错）
  在可靠传输问题上有三种可能的错误：帧丢失，帧重复，帧乱序

# 奇偶校验
奇偶校验是两种校验模式：奇校验，偶校验
**奇校验：通过控制校验位，令算上校验位，一共有奇数个1**
**偶校验：通过控制校验位，令算上校验位，一共有偶数个1**
**现实中更常用偶校验，因为偶校验的硬件实现简单：只需将每位异或运算即可**
例：
规定第一位是校验位，那么100经过
奇校验后：0100
偶校验后：1100
（给第一位前添加了一个校验位）
**优点：**
**需求算力低，易实现**
**缺点：**
**同时偶数个位出错就检测不出来了**
