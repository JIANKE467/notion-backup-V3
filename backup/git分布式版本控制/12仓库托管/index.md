#  12.仓库托管

# git远程仓库
github（线上）
码云（线上）
gitlib（需要自己部署）
# 步骤
1. 先注册远程仓库
1. 创建仓库
1. 配置ssh秘钥（公钥放云，私钥放本地）
- 设置→ssh秘钥→添加秘钥
1. gitbath中验证是否配置成功
```shell
ssh -T git@平台网址
#平台网址指的是gitee.com或github.com,不是你的仓库地址
#执行这个命令要注意本地ssh私钥在本地默认路径上，否则会失败，详见ssh原理
#这是测试登录命令，能执行成功说明远程能用ssh登上
```
1. gitbath中绑定仓库
```shell
git remote add 远程仓库名 仓库地址
#远程仓库名是给远程仓库起的别名，只对本机生效
#远程仓库名一般是“origin”
#一个本地仓库可以绑定多个远程仓库
#不绑定远程仓库就无法执行拉取/推送，因为git不知道本地仓库对应哪个远程仓库（即使能登陆上）
```
推送/拉取/克隆
PS：
查看该私钥的远程仓库有哪些（远程仓库通过私钥来认人）
```shell
git remote
```
# 配置ssh
在shell中生成ssh秘钥对：
```shell
ssh-keygen -t rsa
```
会提示设置文件路径（直接回车表示使用默认路径）
会提示设置密码（直接回车表示不设置密码）
### 默认秘钥路径
**公钥：**
`~/.ssh/id_rsa.pub`
直接cat命令查看
```shell
cat ~/.ssh/id_rsa.pub
```
# ssh连接原理（ssh公钥已配置到服务器）
使用ssh登录→
客户端在本机默认位置寻找私钥→
推导出公钥并发给服务器→
服务器返回一个随机挑战→
客户端用私钥签名并发给服务器→
服务器用公钥验证→
通过/不通过
