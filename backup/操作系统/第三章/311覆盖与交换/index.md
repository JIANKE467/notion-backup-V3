#  3.1.1覆盖与交换

# 覆盖技术
早期计算机内存小，会将程序分为多个段，常用的段常驻内存，不常用的需要在调入内存
内存分一个固定区和若干覆盖区

# 交换技术
在系统内存不足时将内存中部分进程换出外存，时机合适再换回
- 换出外存的状态叫挂起态
- 挂起还可以分为就绪挂起，阻塞挂起
- 被挂起的进程放在外存对换区中（连续分配，速度快）
- 普通文件放在文件区（随机分配，速度慢）
- PCB常驻内存，不会被换出外存
