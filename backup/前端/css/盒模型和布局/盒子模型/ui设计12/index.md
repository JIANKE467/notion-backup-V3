#  UI设计1，2

## 卡片背景和边框
- 卡片背景与网页背景要有区别
- 卡片背景与卡片文字要有对比度
- 可以使用盒子阴影增加质感
## 卡片边距
- 卡片不能没有内边距，否则非常拥挤
- 边距推荐是4的倍数
## 卡片圆角
- 卡片要加一定圆角，否则太生硬
- 圆角越大，内边距就得越大
## 页面颜色
页面颜色要贴近主题
- 蓝色：科技、可信赖、冷静
- 红色：警告、禁止、热情
- 绿色：安全、通过、自然、清新
- 黄色：提醒、高能注意
颜色建议
- 主色（Primary） —— 品牌、主按钮、重点视觉
- 辅色（Secondary）—— 辅助内容、背景分区，一般不会和主色调差别过大
- 强调色（Accent） —— 强调、提醒、交互反馈，建议采用主色调的反色或相差较大的颜色
注意
时刻注意对比度，别太大（难看），别太小（看不清）
