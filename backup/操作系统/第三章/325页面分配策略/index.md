#  3.2.5页面分配策略

# 页面分配策略
  驻留集：系统给某进程分配的真实内存大小，被换出外存的部分不算
  - 驻留集太小会频繁缺页
  - 太大浪费空间
  驻留集分配策略：
  - 固定分配：分配固定大小，不再改变
  - 可变分配：运行期间可动态增减
# 页面置换策略
  - 局部置换：缺页且内存不足时，只置换进程自己的块
  - 全局置换：缺页且内存不足时，在全局范围置换
  PS：
  1. 页面分配策略为固定分配时，无法使用全局置换
  1. 可变分配+全局置换并非最好，会导致其他进程缺页率增加，从而来回争抢，增加开销
# 调入页面策略
  ### 预调页策略：
  根据局部性原理预测需要调入页面，在进程运行前提前调入
  ### 请求调入策略：
  运行时缺页再发出调入请求
# 调入页面路径
  系统将磁盘分为对换区和文件区两部分
  对换区：连续存储（读写快）
  文件区：随机存储（读写慢）
  ### 对换区充足时
  - 所有的调入调出都在对换区进行
  ### 对换区不足时
  - 不需要修改的数据从文件区调入（不用写回）
  - 需要修改的数据从对换区调入

  ### UNIX方式
  - 某文件首次使用（对换区没有），直接从文件区调入
  - 调出时放到对换区，而不是文件区
# 抖动（颠簸）现象
刚调出的块立马又要调入就是抖动现象
原因：分配给进程的物理块不够
工作集：某段时间内进程访问了几个页面
通过统计工作集来决定驻留集大小
