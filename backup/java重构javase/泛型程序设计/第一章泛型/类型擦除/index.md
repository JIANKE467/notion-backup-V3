#  类型擦除

前面已经介绍过，Java的泛型是假泛型，它底层并不支持把类型空着不写，因此在语法上它采用了类似注释的形式来表示泛型，这些”注释“不会被编译进二进制文件，而空缺的类型全部由Object类型代替（没有泛型上界的情况，有泛型上界则全部由泛型上界的类型替代）
