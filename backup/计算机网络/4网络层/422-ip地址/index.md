#  4.2.2 IP地址

# 最初的IP地址分类方案
ICANN将IP地址划分为ABCDE五类
其中ABC类是单播地址
D类是多播地址
E类暂时保留
### IP结构
ICANN将IP分为两个部分：
`<网络号><主机号>`
网络号不定长，通过前几个比特判断是几类地址
### PS
- 路由器和路由器连接可以不分配IP地址
- 同一个网络下的设备网络号要相同
- 电脑新接入时要分配IP地址和默认网关
### 特殊IP地址
| 网络号 | 主机号 | 做源地址 | 做目的地址 | 含义 |
| --- | --- | --- | --- | --- |
| Y | 全0 | x | x | 表示整个网络本身（只能用于路由表，转发表） |
| Y | 全1 | x | ✓ | 在网络号为Y的网络中广播 |
| 全0 | Y | ✓ | x | 表示本网络中的Y主机 |
| 全0 | 全0 | ✓ | x | 表示本网络是的本主机（DHCP中用） |
| 全1 | 全1 | x | ✓ | 向本网络广播 |
| 127 | 非全0 | ✓ | ✓ | 本地环回，用于测试 |
注意⚠️：以上特殊地址不能分配给主机
重要结论：一个网络中主机号占N bit，最多支持2^N-2台设备
