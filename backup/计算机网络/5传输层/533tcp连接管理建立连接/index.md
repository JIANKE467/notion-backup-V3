#  5.3.3TCP连接管理（建立连接）

前提：我们将主动发起连接的叫客户端，被动响应的叫服务器
# 三次握手（标记值）
握手1：客户端→服务器（客户端发起连接）
SYN=1；ACK=0；FIN=0；seq=xx(客户端自定义的值)；ack=无效

握手2：服务器→客户端（服务器确认并回应）
SYN=1；ACK=1；FIN=0；seq=xx(服务器自定义的值)；ack=客户端发来的seq+1

握手3：客户端→服务器（客户端确认）
SYN=0；ACK=1；FIN=0；seq=不变/+n；ack=服务器seq+1
注意⚠️
- 只有握手1，2的SYN=1
- 只有握手1的ACK=0
- 握手1，2不能携带数据，但仍要消耗一个序号（seq+1）
- 握手3可以带数据（带几个字节，消耗几个序号），也可以不带数据（不消耗序号）
# 三次握手（状态转换）
### 客户端
```plain text
连接关闭CLOSED
↓（发送握手1）
同步已发送SYS-SENT
↓（收到握手2&发出握手3）
已建立连接ESTABLISHED
```
### 服务器
```plain text
连接关闭CLOSED&监听LISTEN
↓（收到握手1&发出握手2）
同步已收到SYS-RCVD
↓（收到握手3）
已建立连接ESTABLISHED
```
