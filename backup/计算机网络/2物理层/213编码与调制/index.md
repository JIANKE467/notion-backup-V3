#  2.1.3编码与调制

编码：二进制数据→数字信号
解码：数字信号→二进制数据
调制：二进制数据→模拟信号
解调：模拟信号→二进制数据
# 常用编码方式
  **不归零编码（NRZ）**：
  低0高1，中不变
  - 自同步（时钟同步）：无
  - 浪费带宽（每hz利用率）：不浪费
  - 抗干扰：弱👎🏻

  **归零编码（RZ）：**
  低0高1，中归零
  PS：“中”指的是两个信号之间怎么处理
  - 自同步：有
  - 浪费带宽：浪费
  - 抗干扰：弱👎🏻

  **反向非归零编码（NRZI）**：
  跳0不跳1看起点，中不变（遇到0就跳变一下）
  - 自同步：若增加冗余位，可支持
  - 浪费带宽：浪费一点（冗余位）
  - 抗干扰：弱👎🏻

  **曼彻斯特编码：**
  上跳0下跳1看中间，中必变（一定会在信号中间跳变，是0是1取决于上跳还是下跳）（默认）
  还有一种旧版曼彻斯特编码，与这个相反，上跳1下跳0
  - 自同步：有
  - 浪费带宽：浪费
  - 抗干扰：强👍🏻

  **差分曼彻斯特编码：**
  跳0不跳1，看起点，中必变
  - 自同步：有
  - 浪费带宽：浪费
  - 抗干扰：强👍🏻

# 常用调制方法
### 调幅AM
根据不同振幅区分不同信号
### 调频FM
根据不同频率区分不同信号
### 调相PM
根据每个信号周期中正弦波的相位来区分不同信号
![](assets/3345a2dd-8276-80a5-9dba-fc94d23587c8.jpg)
### 正交幅度调制（QAM）
将调幅信号与调相信号叠加起来
可以增大信息传输密度
