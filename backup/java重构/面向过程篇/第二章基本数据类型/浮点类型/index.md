#  浮点类型

Java 中有这几种浮点类型
- float 单精度浮点型 （32bit，4字节）
- double 双精度浮点型（64bit，8字节）
# 注意：
- 所有小数默认是 double 类型（即使它是一个常量）**（这是Java 众多该死特性中的一个）**（具体含义见下面代码）
```java
float a=1.56  //❌报错，因为数字1.56默认是double型，float精度＜double精度

float a=1.56F //✅正确，给常量后面添加大写/小写F表示这是一个float型常量值
```
- 相反，大范围的double类型可以直接接收小范围的float类型（发生隐式类型转换）
- long类型（64bit）可以自动类型转换为内存更小的float类型（32bit），原因：虽然可能损失精度，但由于float类型带指数所以实际能表示的范围其实是更大的，编译器容许了😇
- 使用浮点类型可能出现下面的情况（**计算机使用2进制表示浮点，部分浮点无法用二进制精确表示**）（解决办法：使用Decimal）
```java
System.out.println(0.1+0.2==0.3)
//结果输出fales
```
# 每日喷Java
Java的自动类型转换（隐式类型转换）的原则原则和c语言一样，并不能用“不丢精度就可以自动转换”或“小范围可以自动转换为大范围”来概括
而是只能根据Java和c规定的转换路径进行转换
这导致了类型转换逻辑非常混乱
go语言完全解决了这个问题（删除了自动类型转换，所有转换必须显式进行）
