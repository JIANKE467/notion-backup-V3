#  第二章：基本数据类型

[整数类型](整数类型/index.md)
  在Java中，整数类型包括以下几个：
  - byte 字节型 （8个bit，也就是1个字节）范围：-128~+127
  - short 短整形（16个bit，也就是2个字节）范围：-32768~+32767
  - int 整形（32个bit，也就是4个字节）最常用的类型：-2147483648 ~ +2147483647
  - long 长整形（64个bit，也就是8个字节）范围：-9223372036854775808 ~ +9223372036854775807
[类型转换](类型转换/index.md)
   Java 中有两种类型转换：隐式类型转换（自动类型转换），显式类型转换（手动类型转换）
  # 隐式类型转换
   这是自动发生的，当不同数据类型的变量进行运算时，范围小的数据类型会转换成范围大的数据类型
  当需要将范围大的数据类型转换成范围小的类型时，隐式转换不会发生，这需要显式类型转换来完成（原则上是这样，但存在特殊情况，如：long（64bit）允许隐式转换成float（32位），这可能损失精度）

  byte→short(char)→int→long→float→double
  # 显式类型转换
  语法
  ```java
(目标类型) 变量名
//注意，这个不完整，仅说明基本写法，实际使用需要将转换完的结果赋值给某个变量
  ```
  eg：
  ```java
int a；
float b=1.35；
a=(int)b;
  ```
[浮点类型](浮点类型/index.md)
  Java 中有这几种浮点类型
  - float 单精度浮点型 （32bit，4字节）
  - double 双精度浮点型（64bit，8字节）
  # 注意：
  - 所有小数默认是 double 类型（即使它是一个常量）**（这是Java 众多该死特性中的一个）**（具体含义见下面代码）
  ```java
float a=1.56  //❌报错，因为数字1.56默认是double型，float精度＜double精度

float a=1.56F //✅正确，给常量后面添加大写/小写F表示这是一个float型常量值
  ```
  - 相反，大范围的double类型可以直接接收小范围的float类型（发生隐式类型转换）
  - long类型（64bit）可以自动类型转换为内存更小的float类型（32bit），原因：虽然可能损失精度，但由于float类型带指数所以实际能表示的范围其实是更大的，编译器容许了😇
  - 使用浮点类型可能出现下面的情况（**计算机使用2进制表示浮点，部分浮点无法用二进制精确表示**）（解决办法：使用Decimal）
  ```java
System.out.println(0.1+0.2==0.3)
//结果输出fales
  ```
  # 每日喷Java
  Java的自动类型转换（隐式类型转换）的原则原则和c语言一样，并不能用“不丢精度就可以自动转换”或“小范围可以自动转换为大范围”来概括
  而是只能根据Java和c规定的转换路径进行转换
  这导致了类型转换逻辑非常混乱
  go语言完全解决了这个问题（删除了自动类型转换，所有转换必须显式进行）
[字符类型](字符类型/index.md)
  - char 字符型（16个bit，也就是2字节，不带符号）范围是0 ~ 65535
  # 注意
  - char类型底层储存的是数字（ASCII码）
  - char类型使用单引号包裹内容
  ```java
char a='字符/转义字符/ASCII码'
  ```
[布尔类型](布尔类型/index.md)
  - boolean布尔类型
  布尔类型只有两个状态true/false
  示例：
  ```java
boolean b = true;
  ```
[局部变量类型推断](局部变量类型推断/index.md)
  从Java10起新增了`var`类型，这是一个万能类型，它会根据输入内容自动选择合适的数据类型
  ```java
var a = 10; // 10会以int类型存储
  ```
