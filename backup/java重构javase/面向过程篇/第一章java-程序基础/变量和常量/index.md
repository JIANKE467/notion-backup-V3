#  变量和常量

# 变量
 Java 定义变量需要手动指定变量的数据类型
```java
数据类型 变量名； 
```
变量名有以下要求：
- 标识符可由大小写字母、数字、下划线(_)和美元符号($)组成，不能以数字开头
- 变量不能重复定义，大小写敏感
- 不能有空格、@、#、+、-、/ 等符号
- 应见名知意
- 不能与关键字重名
PS：Java语法允许使用中文变量名，但不推荐（兼容性极差）
## 变量赋值/定义
可以初始化赋值
```java
int a=1；
```
可以先定义后赋值
```java
int a；
a=1；
```
也可以一次定义多个变量（逗号隔开）
```java
int a，b；
```
# 常量
Java 的常量是基于变量定义的
在变量前加上 final 修饰符，使变量不可修改
```java
final int a；
```
常量赋值后不可修改（未初始化的变量可以赋值一次）
