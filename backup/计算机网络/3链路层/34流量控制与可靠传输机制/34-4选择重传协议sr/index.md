#  3.4-4选择重传协议SR

# 滑动窗口机制
发送窗口W_T＞1，接收窗口W_R＞1
W_R≤W_T
接收窗口不能大于发送窗口
# 帧编号
$$
W_T+W_R≤2^n
$$
# 确认机制
SR不支持累积确认，必须一帧一帧确认
# 重传机制
超时重传
# SR的特殊规则
否认帧NAK_i ：若接收到第 i 帧有错误，则丢弃该帧，并返回否认帧NAK_i
请求重传：发送方接收到NAK_i，则重传第i帧
# 确认帧丢失
与前面相同
# Q＆A
Q：为什么接收窗口要≤发送窗口？
A：如果接收窗口＞发送窗口，比发送窗口大的部分会长期空闲，影响效率
Q：SR协议如何解决丢帧/错帧
A：只要发送窗口移动不会导致需要重传的帧被移动到发送窗口外，就继续移动发送窗口
