#  4.4.5BGP路由选择

# 选择本地偏好值最高的路径
- 本地偏好由系统管理员设置，相当于优先级
- 通常考虑安全，成本
# 选择AS跳数最少的路线
如果本地偏好级别一致则需要使用该方法
AS跳数少不一定路由跳数少
# 使用热土豆路由算法
如果多条线路AS跳数一致则需要使用热土豆算法
理念：数据在本AS内是烫手的土豆，要尽快丢出去
- 根据内部网关协议（RIP/OSPF），找到最快离开本AS的路径
- RIP以跳数为代价，OSPF以路径总长度为代价
# 选择BGP标识最小的路由
如果各路径跳数/代价也一致，则用该方法
- 每台BGP路由器都有唯一标识符
- 选择标识符小的路由器发送
