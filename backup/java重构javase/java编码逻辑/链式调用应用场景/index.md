#  链式调用应用场景

Java的部分框架支持使用链式调用来操作
链式调用的逻辑：方法接收一个对象的引用，在该引用上执行完自己方法的代码后将操作完的对象引用传出，这样就使得后一个方法可以直接跟在后面调用，这便是链式调用的核心原理
因此链式调用不是什么新的底层特性
# 支持的框架
**Stream API（完全支持）：Java集合框架中的流式操作**
Java多线程（部分支持）
…….
# 注意
虽然都是流，JavaIO（即Java文件流）是完全不支持链式调用的
Java多线程中的** ****`Thread`****、****`ExecutorService`****、****`Future`**** **不支持链式调用，**`CompletableFuture`**** **支持链式调用
