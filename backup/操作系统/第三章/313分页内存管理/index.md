#  3.1.3分页内存管理

# 什么是分页存储
分页存储是一种内存管理方式，它可以较好的利用虚拟内存并解决外部碎片的问题
原理：
系统将内存分成固定大小的“页”，将程序也切分为和页大小一样的若干份，并将它们装入页中
- 操作系统将内存分为多个大小相同的分区，每个分区就是一个页框
- 每个页框有一个编号，页框号从0开始
- 将一个进程分成多个和页框大小一样的块，并放入页框
- 操作系统为每个进程维护一个页表

# 术语：
页框=页帧=内存块=物理块=物理页面
页表长度：页表中页表项（Page Table Entry，PTE）的数量，也就是该进程拥有的页数。
# 重要数据结构—页表
系统为每个进程维护一个页表，用于记录页面在内存中的位置（映射页号和块号）
- 页表记录的是块号，不是内存地址
- 页表类似于顺序表，不用专门记录页号
- 页表在内存中是连续存储的
# 地址转换
1. 页号=逻辑地址/页面长度（取整）
（逻辑地址都是从0开始的）
1. 页内偏移量=逻辑地址%页面长度（取余）
1. 查询页表，可知道页框号
1. 页起始地址=页框号×页面大小
1. 实际物理地址=页起始地址+页面偏移量
# 分页的优点
1. 没有外部碎片：
程序页面可以分散存放，不需要连续空间，因此几乎没有外部碎片。
1. 支持虚拟内存：
程序看到的是连续的大地址空间（这对程序是透明的）
