#  5.3.1 磁盘结构HDD

# 磁盘，扇区，磁道
- 磁盘盘面会分为一个个同心的圈，一圈就是一个磁道
- 一个磁道又会被划分成多个扇区，每个扇区就是一个磁盘块，各扇区容量相同
PS：最内侧的扇区数据密度最大
![](assets/3785a2dd-8276-80ee-b09a-f83dcf449846.jpg)
# 盘片，柱面
- 一个磁盘可能有多个盘片，用盘面号标记
- 柱面：所有盘面中相对位置相同的磁道组成柱面
- 读写只需要（柱面号，盘面号，扇区号）即可
![](assets/3785a2dd-8276-805e-8cdc-cc7cc33ec742.jpg)
# 磁盘分类
### 按磁头能否移动分类
- 活动头磁盘（一个磁头）
- 固定头磁盘（多个磁头）
### 按能否换盘片
- 可换盘磁盘
- 固定盘磁盘
